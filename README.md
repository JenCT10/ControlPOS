# ControlPOS — Avance 2

Proyecto Spring Boot con Java 21 y Maven. El esquema y los datos de prueba
están en ControlPOS.sql, para Microsoft SQL Server. El prototipo navegable
se abre directamente con ControlPOS_Prototipo.html.

Se verificaron seis tablas y cuatro terminales de prueba en SSMS.
La conexión desde Spring Boot quedó pendiente de verificación.
La configuración JDBC corresponde a la instancia local de desarrollo.
